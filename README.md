# React GitHub Pages Starter

A client-side-only React application written in JavaScript. It uses Vite for
the development/build toolchain, React Bootstrap for UI components, and React
Router in declarative mode for navigation.

## Requirements

- Node.js 22 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
npm run preview
```

The production files are written to `docs/`.

## Implementation steps

1. Created a Vite React project structure using JavaScript and JSX only.
2. Added React, React DOM, Bootstrap, React Bootstrap, and React Router DOM.
3. Configured Vite with `base: './'` so built asset URLs work beneath a GitHub
   Pages repository path.
4. Imported Bootstrap's compiled CSS once in `src/main.jsx`.
5. Wrapped the application in React Router's `HashRouter` and declared routes
   with `Routes` and `Route` components.
6. Added Dashboard, Budgets, Expenses, and not-found pages plus a responsive
   React Bootstrap navigation bar titled Budget Tracker.
7. Added a GitHub Actions workflow that installs, builds, and deploys `docs/`
   to GitHub Pages after pushes to `main`.

`HashRouter` stores the route after `#` in the URL. GitHub Pages therefore
always serves `index.html`, including when a visitor refreshes a nested route;
no server rewrite or custom `404.html` is needed.

## Deploy to GitHub Pages

1. Push the project to a GitHub repository whose default deployment branch is
   `main`.
2. Open **Settings > Pages** in the GitHub repository.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. Push to `main`, or run **Deploy to GitHub Pages** manually from the Actions
   tab.
5. After the workflow completes, open the URL shown in the deployment summary.

If the repository uses another branch, update the branch name in
`.github/workflows/deploy.yml`.
